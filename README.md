# Group2_ML_FinalProject

Comparative analysis of machine learning models for cannabis use risk classification using Logistic Regression, Naive Bayes, K-Nearest Neighbors, Random Forest, and Support Vector Machine.

## Repository Structure

```text
data/
│── drug_consumption.data

figures/
│── model evaluation figures and visualizations

models/
│── trained machine learning models (.pkl)

notebook/
│── Comparative_Analysis_of_Machine_Learning_Models_...ipynb

tables/
│── generated CSV tables and model summaries
```

## Models Used

- Logistic Regression
- Naive Bayes
- K-Nearest Neighbors (KNN)
- Random Forest
- Support Vector Machine (SVM)

## Contents

The repository includes:
- Data preprocessing and feature engineering
- Model training and evaluation
- Hyperparameter tuning
- Feature importance analysis
- SHAP-based interpretability analysis
- Performance comparison tables and visualizations

## Requirements

Recommended environment:
- Python 3.10+
- Jupyter Notebook

Main libraries used:
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
- shap
- joblib

Install dependencies using:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn shap joblib
```

## Running the Project

1. Clone the repository
2. Open the notebook in the `notebook/` directory
3. Run the notebook cells sequentially
